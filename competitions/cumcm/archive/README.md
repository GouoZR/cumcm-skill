## 收录标准

1. **题目概要**：一句话本质 + 问题类型 + 决策变量/目标/约束核心
2. **数据结构**：附件布局、规模（行×列、sheet 数）——用于推断求解规模
3. **建模思路**：Q1/Q2/Q3 的递进建模路线（确定性→不确定性→相关性）
4. **优秀论文标答**：全国优秀论文摘要中的关键数值，用于验证代码正确性
5. **建模要点**：从标答反推的加分项和避坑点

## 使用方式

- **验证代码**：实现后用标答数值对照，检查模型/求解器是否实现正确
- **学习加分项**：看优秀论文如何刻画风险（灾害因子）、相关性（替代/互补）等细节
- **走查对标**：用本库题目跑 skill 流程，与标答对比暴露 skill 缺口

> ⚠️ 标答是单篇优秀论文的结果，不是官方唯一答案；不同方法（精确/启发式）会得到略有差异但同量级的结果。
