# 数学模型目录 (model_catalog)

> 常用数学建模方法的候选目录，按问题类型组织。它用于扩大候选集，不根据题目关键词自动选型。每个候选仍需检查输出形式、数据条件、假设、约束、计算预算和验证方法。

## 0. 问题类型 → 候选模型族（stage 3 生成候选时参考）

| 题目特征 | 可检查的候选模型族 |
|-------------------------------------------------|-------------------------------------|
| "求最优..." / "如何分配..." / "在约束下使...最大" | **优化类** (LP/IP/NLP/启发式) |
| "预测..." / "未来..." / "时间序列" | **预测类** (回归/ARIMA/灰色/LSTM) |
| "评价..." / "排名..." / "综合得分" | **评价类** (AHP/TOPSIS/熵权/模糊) |
| "判断..." / "归类..." / "识别..." | **分类类** (Logistic/SVM/决策树/NN) |
| "模拟..." / "如果...会怎样" / "随机..." | **仿真类** (蒙特卡罗/系统动力学/ABM) |
| "网络中..." / "路径..." / "流量..." | **图论类** (最短路/最大流/最小生成树) |
| "概率..." / "分布..." / "假设检验" / "抽样" / "期望成本" | **统计决策类** (描述统计/检验/抽样方案/风险决策) |
| "沿路径运动..." / "链条/刚体" / "碰撞/相交" / "曲率/弧长" | **几何/运动学类** (参数曲线/多体递推/碰撞检测/几何优化) |
| "动态..." / "随时间..." | **动力系统类** (ODE/PDE/差分方程) |

## 1. 优化类 (Optimization)

### 0. 求解规模 → 算法选择（重要）

优化模型的**规模**决定用精确求解器还是启发式。规模暴涨时，精确求解器（MILP/GUROBI/CBC）可能超时，需降维或换启发式。

| 变量规模 | 建议 | 说明 |
|---------|----------------------------------|--------------------------------------|
| < 1 万 | 精确求解器（cvxpy + GLPK_MI/CBC） | 可求最优解，论文有"最优"支撑 |
| 1万 ~ 5万 | 精确求解器 + 分层/降维 | 尝试精确求解，超时则降维 |
| > 5万 | 启发式（遗传算法/粒子群/模拟退火） | 求近似最优，需报告停止条件与可解释基线 |

**实例（2024 C 题）**：多期（7年）× 地块（54）× 作物（42）组合后约 47628 变量，已接近阈值上限。全国优秀论文选择**遗传算法**求解而非 MILP——这正是规模驱动的选择。实际求解时可先用类型匹配矩阵降维，再决定精确/启发式。

**判断方法**：建模时先估算 `决策变量数 = 期数 × 地块数 × 季数 × 作物数 × 0-1 辅助`，对照上表选算法。

### 1.1 线性规划 LP
- **适用**: 目标 + 约束都线性
- **Python**: `scipy.optimize.linprog`, `cvxpy`, `pulp`
- **变体名**: "考虑动态权重的多目标线性规划", "鲁棒线性规划"
- **示例场景**: 调度、配送、资源分配；是否适用取决于线性关系与约束表达

### 1.2 整数规划 IP / 0-1 规划
- **适用**: 决策变量取整数 / 0-1
- **Python**: `cvxpy + GUROBI/CBC`, `pulp`
- **变体名**: "基于分支定界的混合整数规划", "Lagrangian 松弛 IP"
- **示例场景**: 选址、路径、组合；需核对整数变量规模与可用求解器

### 1.3 非线性规划 NLP
- **适用**: 目标或约束含非线性
- **Python**: `scipy.optimize.minimize` (SLSQP, trust-constr), `cvxpy` (DCP)
- **变体名**: "凸近似 NLP", "二阶锥规划 SOCP"

### 1.4 多目标规划
- **适用**: 多个相互冲突目标
- **方法**: 加权法 / ε-约束法 / NSGA-II
- **Python**: `pymoo`, `deap`
- **变体名**: "基于熵权的多目标规划", "Pareto-NSGA-II"
- **选型提醒**: 目标之间需存在真实权衡，并说明权重或 Pareto 方案的决策依据

### 1.5 动态规划 DP
- **适用**: 阶段决策、最优子结构
- **Python**: 自实现 (numpy + memoization)
- **变体名**: "状态压缩动态规划", "近似动态规划 ADP"

### 1.6 启发式算法
- **遗传算法 GA**: `deap`, `pygad` — "自适应交叉率 GA"
- **粒子群 PSO**: `pyswarms` — "改进惯性权重 PSO"
- **模拟退火 SA**: 自实现 — "自适应温度 SA"
- **蚁群 ACO**: 自实现 — "信息素改进 ACO"
- **示例场景**: 大规模组合优化、多峰目标；需报告停止条件、随机种子和与可解释基线的比较

### 1.7 鲁棒优化 / 随机规划
- **适用**: 参数不确定
- **Python**: `cvxpy` (robust constraints), `Pyomo`
- **变体名**: "基于场景的随机规划", "Wasserstein 鲁棒优化"
- **选型提醒**: 只有不确定性集合、概率或场景来源有依据时，才使用鲁棒优化或随机规划

## 2. 预测类 (Prediction)

- **变体名**: "弹性网回归", "贝叶斯线性回归"

### 2.2 时间序列经典

### 2.3 灰色预测
- GM(1,1): 自实现；可作为小样本、近指数趋势数据的候选，需先检验适用条件并做留出验证
- **变体名**: "残差修正 GM(1,1)", "GM(1,N) 多变量灰色模型"
- **验证提醒**: 用滚动或留出验证与合适基线比较，不因组合方法名称而默认更优

### 2.4 机器学习预测

- LSTM: `tensorflow.keras` / `torch`
- **变体名**: "改进 LSTM-Attention 时序预测", "XGBoost-LightGBM Stacking"

### 2.5 组合预测
- **核心思想**: 多模型加权 (权重由误差倒数 / 熵权 / AHP 给出)
- **变体名**: "基于熵权的 ARIMA-LSTM 组合预测"
- **选型提醒**: 组合模型只在子模型误差具有互补性且留出集结果支持时采用，并报告权重与消融结果

### 7.6 接受抽样 / 统计决策 (Acceptance Sampling)
- **适用**: 抽检方案 (n, c)、拒收/接收规则、生产方/使用方风险权衡、期望成本决策
- **核心对象**: OC 曲线 (操作特性曲线)、α/β 双风险、序贯抽样
- **Python**: `scipy.stats.binom`/`poisson` 精确搜索 (n, c)
- **必查 sanity check**: 方案须满足 `c < n`（c=n 时永不拒收 = 不检测，伪解）；两类错误概率都应真实小于容限；最小化 n 的朴素解要判量级是否工程上荒谬
- **示例场景**: 零配件抽检、批次接收、质量控制的成本-风险权衡（2024 B 题 Q1）

## 8. 几何/运动学类 (Geometry & Kinematics)

### 8.1 参数曲线几何
- **适用**: 沿给定曲线的弧长、曲率半径、切线/法向、等距(等螺距)螺线等
- **Python**: `numpy` 数值积分弧长, `sympy` 符号求导
- **示例**: 等距螺线弧长公式 $s=\frac{a}{2}[\theta\sqrt{1+\theta^2}+\ln(\theta+\sqrt{1+\theta^2})]$，曲率半径 $\rho=(1+y'^2)^{3/2}/|y''|$（2024 A 题 Q1）
- **注意**: 弧长优先用闭式公式或高精度数值积分；曲率/切向用符号或数值求导核对单位

### 8.2 多刚体链条递推
- **适用**: 一串刚性杆(板)首尾铰接、沿固定路径运动的位形求解
- **核心**: 相邻间距约束 $\|P(\theta_{i+1})-P(\theta_i)\|=d_i$ 与路径位置约束联立，逐刚体数值求根
- **Python**: `scipy.optimize.brentq` / `fsolve` 逐刚体递推，向量化加速
- **必查 sanity check**: 链条速度分布必须与驱动速度同阶。若末端速度偏离驱动速度达数量级，说明模型忽略了几何放大/曲率耦合，须回 stage 5 重构约束而非采信
- **示例**: 板凳龙 224 把手沿等距螺线递推（2024 A 题 Q1/Q5；简化模型得 2 m/s，真解 1.33 cm/s，相差约 150 倍）

### 8.3 碰撞检测
- **适用**: 判断物体是否相交/碰撞、计算最小间距
- **方法**: 分离轴定理 SAT / 线段-线段距离 / 多边形相交
- **Python**: `shapely` (几何相交), `trimesh` (三维), 自实现 SAT
- **示例**: 板凳龙相邻把手最小间距 vs 板宽阈值（2024 A 题 Q2）

### 8.4 几何约束优化
- **适用**: 在几何/空间约束下求最优参数（如最小螺距、调头空间、转弯半径）
- **Python**: `scipy.optimize` + 数值几何求值
- **注意**: 几何约束常与板长、间隙、曲线曲率强耦合，需把几何量显式纳入优化变量

## stage 3 选型 checklist

对进入决策矩阵的候选记录:
- [ ] 来自哪个族 (1-11)
- [ ] 与题目输出、数据、约束和评价指标的对应关系
- [ ] 关键假设及其证据或可检验方式
- [ ] Python 实现路径 (库/自实现)
- [ ] 规模、复杂度、求解器与比赛时间预算
- [ ] 验证计划、基线和失败条件
- [ ] 不选候选及不选理由

候选数量和差异程度由实际决策不确定性决定。存在方法权衡时，应比较假设或求解机制不同的候选；没有合理替代方案时，不为凑数引入不适用模型。

## §12 历年类比的使用边界

仓库曾收集 91 份来源文档，但当前不随仓库分发 PDF；分位统计只来自 59 份可提取文本，且以 2023 年样本为主、另含 1 份 2025 年文本，没有可用于统计的 2024 年文本。因而不能从这批材料推出“某年份某题应使用某模型”的稳定映射。

使用历年题时应遵循以下证据链:

1. 先读取当届题面，写明输出、数据、约束和评价指标。
2. 若引用历年题作类比，保存可访问来源并指出相同与不同条件。
3. 从本目录生成候选族后，用当前数据做最小可运行验证和基线比较。
4. 只有模型机制、输入条件和验证结果都支持时，才保留该类比；题目动词相似本身不是选型证据。
