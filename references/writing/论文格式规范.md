# CUMCM 论文格式规范

## 唯一权威来源

论文内容结构与格式必须遵循当届官方规则和官方模板。常用官方入口：

- 全国大学生数学建模竞赛：`http://www.mcm.edu.cn/`
- CUMCM 2026 论文格式规范：`https://www.mcm.edu.cn/upload_cn/node/775/cQMeL0YY905244c8bd4b9af832f1699446d8385e.pdf`

竞赛规则可能更新。生成前必须确认届次和官方文件版本，不能把本 Skill 的默认值当作永久规则。

### CUMCM 篇幅的硬约束与质量目标

- 2026 年官方《全国大学生数学建模竞赛论文格式规范》规定摘要原则上不超过一页、正文不超过 30 页，没有规定最低 15000 字或最低 20 页。
- 为防止论文过短，工具默认用约 15000 字词单位和约 20 页作为 CUMCM 完整度质量目标；它们不是官方最低要求，可由当届规则或用户要求覆盖。
- 页数必须以 `paper.docx` 渲染成 PDF 后的实际页数为准，不能根据字符数猜测。

## Markdown → DOCX 转换

本 skill 的写作产出是 `paper_workspace/*.md`，由 Stage 8 §8 装配为 `paper.md`，再由用户执行：

```bash
pandoc paper.md -o paper.docx \
  --from markdown --to docx \
  --number-sections \
  --toc --toc-depth=3 \
  --resource-path=figures/
```

pandoc 原生把 Markdown 公式、图片引用和表格转换为 Word 内容；不需要额外的模板引擎或 LaTeX 编译步骤。若官方发布了 `.docx` 模板，可用 `pandoc --reference-doc=当届官方模板.docx` 保留其样式（页边距、字体、编号格式）。

## 公式

- 公式一律用 LaTeX 数学模式 `$...$`（行内）/ `$$...$$`（块级）书写；pandoc 会把它们转换为 Word 原生 OMML，可编辑、不是截图。
- 矩阵、分段函数等复杂公式转换后必须打开 `paper.docx` 人工核对渲染是否正确；pandoc 对个别复杂环境的处理并非总是完美。
- 未知命令、未闭合分组会在 DOCX 中呈现为原始 LaTeX 文本，需在渲染抽检时发现并修正。

## 表格与图

- 表格必须可编辑：用标准 Markdown table 语法书写，pandoc 自动转换为 Word 表格；复杂表格可另存 `tables/*.csv` 作为源数据。
- 图来自编程手真实运行结果，可从候选图中选择；概念图与数据图的分工见 `stage_08_writing.md §5`。
- 每幅图和每个表必须有连续编号与题注，并在正文中至少引用一次；单位和数值必须一致。

## 校验

没有独立于渲染结果的结构校验脚本；篇幅、公式/图/表数量、图表编号与正文引用、参考文献双向对应等项，按 `references/writing/自审框架.md` 逐项人工核对，并在 `paper.docx` 渲染成 PDF 后做 Stage 9 的渲染抽检（分页、页眉页脚、公式和图表无异常）。2026 年 CUMCM 正文 30 页上限是已核验的官方硬约束；15000 字词单位、20 页、8 幅图等均为完整度质量目标，非官方最低要求，降低时必须记录官方条款或用户要求。
