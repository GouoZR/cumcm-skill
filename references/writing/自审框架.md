# 论文自审框架

本清单是论文手的作者自检，不替代 `W1`、`W2` 独立 Subagent 验收。

## 一、官方规则

- [ ] 已记录目标竞赛、届次、官方规则和官方模板来源。
- [ ] 页面、摘要页、编号、页数、字体、提交格式等逐项符合当届官方文件。
- [ ] 未把本 Skill 默认值或往届经验写成官方规定。

## 二、内容与证据

- [ ] 长篇正文前的证据大纲已由独立质检 Subagent 执行 `W1` 并返回 `PASS`。
- [ ] 每个结论都有真实代码结果、图表、公式或文献支撑。
- [ ] 摘要中的数值与正文、表格、图和复现清单一致。
- [ ] 每道子问题最多两个独立模型体系；物理模型的不同近似按模型族说明清楚。
- [ ] 没有虚构背景数据或未核验引用。
- [ ] 局限和适用边界具体、可追溯。

## 三、文档结构

- [ ] 公式在 `paper.md` 中用 LaTeX 数学模式 `$...$`/`$$...$$` 书写，pandoc 转换后是可编辑 OMML，不是公式截图。
- [ ] `paper_workspace/*.md` 与装配后的 `paper.md`、渲染出的 `paper.docx` 正文、数据、图表和结论一致。
- [ ] 已核对正文篇幅与 `paper.docx` 渲染成 PDF 后的实际页数；官方硬约束和非官方质量目标已明确区分。
- [ ] 默认至少包含 8 幅正式图，其他竞赛与 CUMCM 使用同一图数基线；若按官方规则或用户要求调整，已记录依据。
- [ ] 每个子问题至少有 1 幅正式图支撑关键结论，没有把全部图集中在问题一或单一子问题。
- [ ] 表格可编辑，每幅图和每个表都有连续编号、题注及正文引用，没有孤儿图表。
- [ ] 参考文献与正文引用双向对应，DOI 和出版信息已核验。
- [ ] 不含 `[待补充]`、模板示例正文或临时占位符。

## 四、技术验证

- [ ] `pandoc paper.md -o paper.docx --from markdown --to docx --number-sections --toc --toc-depth=3 --resource-path=figures/`（见 `写作规范.md`/`stage_08_writing.md §8`）执行无错误，且转换过程中的 pandoc 警告均已逐条核查，不存在被忽略的警告。
- [ ] 复杂公式（矩阵、分段函数等）转换后已打开 `paper.docx` 人工核对渲染是否正确，未知命令或未闭合分组导致的原始 LaTeX 文本已修正。
- [ ] 渲染抽检通过，分页、页眉页脚、公式和图表无异常。
- [ ] 默认交付 `paper.docx`；用户明确要求其他格式时已按要求调整。
- [ ] 所需格式冻结后已由独立质检 Subagent 执行 `W2` 并返回 `PASS`。
- [ ] `W1`、`W2` 通过后相关正文、数据、图表和规则未发生未经复验的实质变化。
